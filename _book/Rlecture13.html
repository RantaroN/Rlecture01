13  ダミー変数

13.1 ダミー変数とは

　これまでの重回帰分析の例では、全て独立変数は量的変数であった。教育年数も収入もすべて、連続的な値を取る量的変数である。しかし、多くの研究では質的変数を独立変数として投入したい状況に出くわす。たとえば、階層帰属意識を従属変数とする分析の場合、性別を独立変数として投入することで、性別が階層帰属意識に与える影響を検討したい場合が考えられるだろう。このような場合、どうすれば良いのか。

　質的変数を回帰分析の独立変数に投入したい場合、ダミー変数が活用できる。ダミー変数とは、ある質的変数のカテゴリに当てはまる場合に1が、当てはまらない場合に0が割り振られる二値の変数のことである。たとえば性別の場合、「男性ダミー」と「女性ダミー」というダミー変数を作成することが可能である。Aさんが男性の場合、男性ダミー変数には1が、Bさんが女性の場合、男性ダミー変数には0が入る。

13.2 ダミー変数の回帰分析への投入

　回帰分析では、このようなダミー変数を独立変数に投入することができる。その際、投入できるダミー変数の数は、（質的変数のカテゴリ数-1）である。性別のカテゴリ数が2であると仮定した場合、投入できるダミー変数の数は(2-1=1)個である。都道府県変数の場合、投入できるダミー変数の数は、(47-1=46)個である。たとえば、女性ダミーを回帰分析に投入した場合の回帰式は、以下のようになる。

\[ y_i = b_0 + b_1x_i + b_2female + e_i \]

　何はともあれ、ひとまずRで実装してみよう。以降では、これまでに例示してきた教育年数・収入に加え、性別を独立変数に加え、階層帰属意識の決定要因に迫る。

# まず、女性ダミー変数を作成
# sex変数は1=男性、2=女性なので、これを1=女性、0=男性と変更する
data4 <- data4 |>
  mutate(female = ifelse(sex==2,1,0))

# 作成結果を確認：きちんと1=女性、0=男性となっている
data4 |> count(sex,female)
  sex female   n
1   1      0 499
2   2      1 501
# 次に、これまで通り重回帰分析を実行
lm(sss_scale ~ eduy_scale + income_scale + female, data = data4) |> msummary(stars = TRUE)

　結果を確認してみよう。femaleの偏回帰係数は0.135で、“+”マークがついている。この”+“マークは、10%水準でしか帰無仮説（偏回帰係数=0）を棄却できないことを意味するため、一般的に使用される有意水準5%のレベルでは帰無仮説が棄却できないことを意味する。すなわち、母集団において性別は階層帰属意識に影響を与えていない可能性が排除できない。

　この女性ダミーの分析結果は、何を意味するのだろうか。これは、比較対象（参照カテゴリ）となる男性と比較して、女性の場合に階層帰属意識が0.135上昇することを意味している。（とはいえ今回の結果は帰無仮説を棄却できないので、そうはいえないが…）

　このような分析は、性別のような二値（性別が二値であると仮定することはナンセンスであろうが、一旦仮定する）以外の質的変数でも行うことができる。たとえば、教育年数の代わりに、学歴（中学高校/専門・短大等/大学大学院の3カテゴリ）を独立変数に投入すると、以下のような回帰式になる。

\[ y_i = b_0 + b_1x_i + b_2D_1 + b_3D_2 + e_i \]

　ここで、\(D_1\)と\(D_2\)は、3つのカテゴリを持つ学歴変数のうち、2つのダミー変数を意味する。たとえば、中学高校を参照カテゴリとした場合、投入されるダミー変数は、専門・短大等（\(D_1\)）と大学大学院（\(D_2\)）の2つである。実際にRで分析してみよう。

# まず、学歴（3カテゴリ）の質的変数を作成
data4 <- data4 |>
  mutate(edu = case_when(ZQ23A==1 ~ 1, # 中学=1
                          ZQ23A==2 ~ 1, # 高校=1
                          ZQ23A<=4 ~ 2, # 専門・短大等=2
                          ZQ23A==5 ~ 3, # 大学=3
                          ZQ23A==6 ~ 3, # 大学院=3
                          TRUE ~ NA))
data4 |> count(edu)
  edu   n
1   1 255
2   2 322
3   3 412
4  NA  11
# このままでは、Rはedu変数を量的変数として扱う。そのため、factor()で質的変数であることを宣言する
data4 <- data4 |>
  mutate(edu_cat = factor(edu))

# 質的変数となったedu_catを、重回帰分析に投入
lm(sss_scale ~ income_scale + female + edu_cat, data = data4) |> msummary(stars = TRUE)

　分析結果を見てみると、独立変数の箇所に、“edu_cat2”と”edu_cat3”が含まれているのがわかる。“edu_cat2”は、edu_cat=2のことで、この場合は「専門・短大等ダミー」のことである。“edu_cat3”は、edu_cat=3のことで、この場合は「大学・大学院ダミー」のことである。さて、分析結果を見てみると、“edu_cat1”、すなわち「中学・高校ダミー」が含まれていない。これは、「中学・高校ダミー」が参照カテゴリとして設定されているためである。

　この分析結果からは、参照カテゴリである中学・高校と比べ、専門・短大等の学歴を持つ人は、階層帰属意識が0.183高いことがわかる。大学大学院でも同様に、中学・高校と比べ、階層帰属意識が0.493高いことが示されている。

　Rでは、factor()によって質的変数にされた変数は、自動的に1が参照カテゴリとして使用される。この参照カテゴリを変更したい場合には、factor()内で意図的に設定することができる。

# factor()内のlevels=で、質的変数の順序を設定
data4 <- data4 |>
  mutate(edu_cat_new = factor(edu, levels = c(2,1,3)))

lm(sss_scale ~ income_scale + female + edu_cat_new, data = data4) |> msummary(stars = TRUE)

　factor()内の”levels =“では、質的変数の順序を設定することができる。この順序で1番目に指定されたカテゴリが、lm()では自動的に参照カテゴリとなる。

Noteグループ・ワーク
