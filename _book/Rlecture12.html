12  重回帰分析と統計的統制

12.1 重回帰分析とは

　単回帰分析の授業では、教育年数が階層帰属意識に与える影響について、教育年数を独立変数、階層帰属意識を従属変数とした分析の例を取り上げた。しかし、もし「教育年数が階層帰属意識に与える影響」を知りたい場合、教育年数と関連する収入も統制する必要があるかもしれない。つまり、収入は、教育年数と階層帰属意識の両方に影響を与えるので、教育年数が階層帰属意識に与える影響は、（少なくともその一部は）収入が高いことによる影響かもしれない。

　このように、他の要因を統制した上で、独立変数が従属変数に与える影響を知りたい場合、重回帰分析が役に立つ。重回帰分析とは、独立変数が複数ある回帰分析のことであり、ほとんどの回帰分析では、単回期分析ではなく重回帰分析が使用される。式で表すと以下の通り。

\[y_i = b_0 + b_1x_{1i} + b_2x_{2i} + ... + b_mx_{mi} + e_i\]

　この式では、\(m\)個の独立変数が投入されている。\(b_1\)は、他の独立変数の影響を全て一定にした場合の、\(x_1\)という独立変数が従属変数に与える影響を意味している。ここで、\(b\)を、偏回帰係数と呼ぶ。

　重回帰分析をRで行う方法は極めて簡単である。以下では、独立変数に教育年数（eduy）と収入（income）を、従属変数に階層帰属意識（sss）を使った重回帰分析の方法を示す。

lm(sss ~ eduy + income, data = data4)

Call:
lm(formula = sss ~ eduy + income, data = data4)

Coefficients:
(Intercept)         eduy       income  
   1.676588     0.202887     0.001722

　lm()内で重回帰分析を行う際には、複数の独立変数を、“~”に続けて”+“で結んで記述すれば良い。結果の見方は、単回期分析の際と同様である。この例では、教育年数の偏回帰係数は0.202887、収入の偏回帰係数は0.001722となっている。単回期分析と同様に、msummary()を使用すれば、見やすい結果を得ることができる。

12.2 標準化偏回帰係数

　さて、先ほど出力した重回帰分析の結果を眺めてみよう。教育年数と所得の偏回帰係数を比べてみると、教育年数の方が大きい。このことから、「教育年数の方が収入よりも、階層帰属意識を強く規定する」と言えるのだろうか。

　重回帰分析ではこのように、独立変数間の影響の強さを比較したい状況がある。この際に、偏回帰係数では、適切に比較できない。なぜなら、独立変数の単位が異なるからである。教育年数1年分の上昇と、収入1円の上昇を、フェアに比較することはできないだろう。そこで使用されるのが、標準化偏回帰係数である。

　標準化偏回帰係数を求めるには、全ての変数を標準化すれば良い。標準化とは、平均=0、分散=1に変数を調整する方法である。Rでは、scale()関数を使うことで、変数を標準化することができる。以下ではまず、教育年数と収入の変数を標準化してみる。

data4 <- data4 |>
  mutate(eduy_scale = scale(eduy),
         income_scale = scale(income),
         sss_scale = scale(sss))

# 標準化できているか確認する

12.3 多重共線性

　重回帰分析を実施する際には、多重共線性に気をつける必要がある。多重共線性とは、独立変数間の相関が高い時に、回帰分析の結果が不安定になり、誤った結果を導き出してしまうものである。数学的には、重回帰分析では、独立変数同士の相関がないことを仮定しているが、実際の分析では独立変数間の相関は通用存在する。多少の相関では問題ないが、相関が強すぎると、結果に影響を及ぼす。多重共線性の深刻さを測る指標として、分散拡大要因（VIF）という指標がある。

　Rでは、VIFは以下のようにして計算する。carパッケージのvif()という関数を使用する。

library(car)
lm(sss_scale ~ eduy_scale + income_scale, data = data4) |> vif()
  eduy_scale income_scale 
    1.007643     1.007643

　今回の分析結果では、VIFは1程度である。多重共線性の目安は、以下を参考にすると良い。多重共線性の問題が生じる可能性がある場合には、いずれかの独立変数をモデルから除外することが望ましい。

\(VIF\)の値 多重共線性の問題
\(VIF=1\) 全く問題はない
\(1<VIF<5\) 許容範囲
\(VIF>10\) 多重共線性の問題あり
